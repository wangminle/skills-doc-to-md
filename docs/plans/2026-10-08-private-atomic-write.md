# BUG-037 私有原子写入修复计划

**目标：** 覆盖私有 Markdown 或 sentinel 时，临时文件从创建到替换均不扩大原权限；新文件仍遵循调用者 umask。

**方案：** 在创建临时文件前调用 _path_status 查询目标；既有普通文件将原权限传给 _open_exclusive_temp 的 mode 参数，其他目标使用默认 0666。内核应用 umask 后的权限只会比原权限更严格；写完后继续对齐原权限，保持现有最终权限语义。不查询或修改进程 umask，不改变随机短名与独占创建策略。

**取舍：** 仅在写完后 chmod 会暴露正文；先以宽权限创建再立即 chmod 仍允许旁观者提前打开空文件。本方案在创建时就限制权限，无需增加依赖。
